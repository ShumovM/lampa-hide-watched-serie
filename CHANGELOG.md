# Changelog

Изменения проекта по версиям плагина.

## 1.5.0

- Добавлена синхронизация между устройствами через Supabase: отметки фильмов, история `Lampa.Timeline`
  и последняя раздача сериала.
- Добавлена локальная очередь для офлайн-изменений, фоновый push/pull, постраничная загрузка,
  объединение по времени обновления и tombstones для снятых отметок.
- В синхронизации раздач передаётся `magnet`; приватное поле `link` и хеш торрента не отправляются.
- Добавлены Edge Function `swift-task`, SQL-миграция и отдельные GitHub Actions для функции
  и ручного применения миграций.
- Исправлена регистрация трёх текстовых полей Supabase в настройках Lampa 3.4.8: для `input`
  передаётся пустая карта `values`, необходимая механизму отображения `SettingsApi`.
- Исправлен CORS preflight функции: ответ `OPTIONS` со статусом 204 теперь не содержит тела.
- Отметка фильма получила зелёный треугольный уголок с белой галочкой вместо круглого бейджа.
- Добавлен отдельный раздел «Статистика»: уникальные фильмы, сериалы, аниме и серии с дедупликацией
  по Timeline-привязкам, разбивкой известной длительности и предупреждением о неполной истории.
- Добавлена отдельная главная лента «Избранное» на основе штатных закладок Lampa; начатые фильмы и
  сериалы исключаются из ленты, а штатная закладка снимается автоматически, если API это позволяет.
- Лента избранного адаптирована для обеих веток: `ContentRows.add()` в Lampa 3.x и обёртка главных
  данных `Api.sources.tmdb.main()` в Lampa 2.3.0. Отдельное хранилище избранного не добавлялось.
- Исправлен порядок главных лент: итоговый callback Favorite ставится первым, штатный Continue —
  строго вторым, остальные ленты сохраняют свой относительный порядок. В legacy-массиве 2.3.0
  применена такая же нормализация; одного индекса регистрации строки для 3.x оказалось недостаточно.
- Для сборок 3.x, где callback штатного Continue не удаётся распознать, добавлен fallback на
  `Favorite.continues('tv')`; дублирующий ряд Continue подавляется.
- Исправлено открытие статистики на телевизоре: пункт настроек теперь запускает экран через
  `Lampa.Component.add()` и `Lampa.Activity.push()` вместо модального окна.
- Длительность суммируется только из известных `Timeline.duration`; неизвестные значения не заменяются,
  дополнительные запросы к TMDB и изменения Supabase-схемы не требуются.
- Исправлен lifecycle экрана статистики: компонент реализует `start()`/`stop()`, которые вызывает Activity Lampa.
- Для категорий с неизвестной длительностью и нулевой известной суммой показывается «Нет данных», а не `0 ч`.
- Добавлены проверки lifecycle экрана и legacy Timeline без надёжной привязки; hash не используется для
  угадывания карточки, а позиция воспроизведения не считается длительностью.
- Добавлены проверки UI-бейджа и HTTP-сценариев Edge Function.

## 1.4.0

- Добавлен бейдж для досмотренных завершённых сериалов на карточках каталога и странице сериала.
- Статус завершения определяется по данным TMDB и истории просмотра; новые или непросмотренные серии
  снимают бейдж.

## 1.3.0

- Добавлена кнопка «Продолжить» с последней использованной раздачей сериала.
- При открытии списка файлов курсор устанавливается на следующую или последнюю частично просмотренную серию.

## 1.2.0

- Добавлена отдельная отметка фильма «Просмотрено» с кнопки на странице фильма и отображением на постере.
- Отметка не меняет штатные закладки и прогресс просмотра Lampa.

## 1.1.0

- Добавлена массовая отметка всех вышедших серий просмотренными.
- Добавлена проверка ошибок сезонов и защита от отметки будущих или недатированных серий.

## 1.0.0

- Добавлено скрытие полностью просмотренных сериалов из строки «Продолжить просмотр».
- Добавлен возврат сериала после выхода новой серии.
- Добавлена поддержка двух API-веток: Lampa 2.3.0 (`Favorite.continues`) и Lampa 3.x (`ContentRows.call`).
